# Stage II·a — The Endeavor Sentence (compose once, freeze forever)

The whole petition stands on one canonical sentence, repeated VERBATIM in
every document. After filing, USCIS treats rewording as a potential material
change — a denial risk. Compose it carefully in `endeavor.md`, then never
paraphrase it anywhere.

## The three-part composer

Interview the user for three bounded inputs (each ≤50 words):
1. **Method/approach** — active verbs, at most 3 primary methods
2. **Specific topic/focus** — what the methods act on
3. **Impact** — the "in order to …" clause: what it enables for the U.S.

Mechanical template:
> "My proposed endeavor is to [METHOD] [TOPIC] in order to [IMPACT]."

Then polish into 2-3 candidates. Requirements for the winner:
- Specific enough to be evidenced; broad enough to survive a change of
  employer, project, or application domain
- Organized around one unified theme with 2-3 mutually reinforcing pillars;
  any employer is "the deployment pathway", never a pillar
- Research-framed (academic/research endeavors face less Prong-1 scrutiny
  than industry framings) — without misrepresenting the actual role
- The topic must sit inside the applicant's degree field (Jan-2025 policy
  requires explicit degree–endeavor alignment)

## The six executability elements (score 0/1/2 each)

For each planned project under the endeavor, check:
1. Real-world need · 2. Application scenario · 3. Implementation path ·
4. Beneficiaries · 5. Quantifiable impact · 6. **Means of execution**
(funding, people, entity, compute, collaborators)

0 = absent, 1 = asserted, 2 = evidenced. **Means of execution is the
pass/fail line**: a project with 1-5 but no 6 reads as "a personal plan" —
the profile that draws RFEs and denials. Do not proceed to drafting while
it scores 0; gather the evidence or reframe the project first.

## Record in endeavor.md

```markdown
# Proposed Endeavor (FROZEN 2026-08-01 — do not reword)
My proposed endeavor is to ...

## Pillars
1. ... 2. ... 3. ...

## Planned projects (2-3, FUTURE work only)
### Project 1: [gerund title]
- need / scenario / implementation path / beneficiaries / quantifiable impact
- means of execution: [funding, collaborators, infrastructure]
- start: [MM/YYYY] at [institution] (past tense if started)
- element scores: need 2 · scenario 2 · path 1 · beneficiaries 2 · impact 1 · means 2

## Six-element summary + advice
```

Once the user confirms, mark it FROZEN with the date. Every later document
must quote the sentence exactly; check this during drafting review.
